Overview & context

Without reference transcripts, “sounds plausible” is not evidence.

Navigation dialect ASR must handle accents and place names while avoiding loops, sentence repetition, abnormal length, and invalid characters.

Problem

Long GPU jobs may lose progress when a process exits. A single decoding strategy is not robust enough for anomalies, and retry or post-processing rules must not become an untraceable black box.

CORE RULEDo not rewrite normal samples

Only quality-gate failures enter constrained retry.

NO CLAIMNo CER claims without ground truth

Quality gates detect obvious generation failures; they do not replace formal evaluation.

Architecture

Robustness is part of the production inference path.

Each stage has a defined input, failure path, and persistent evidence.

01 · SHARDFixed shards

Split audio deterministically for resume.

02 · INFERPrimary model

One greedy decode for normal samples.

03 · GUARDAnomaly detection

Detect repetition, length, and character anomalies.

04 · RETRYRetry / fallback

Constrained retry, then legacy model as needed.

05 · BUILDNormalize & validate

Build JSONL, audit records, and SHA-256.

Technical decisions

Controlled variables matter more than adding models blindly.

01

Freeze the model route

No further training in the current phase, preventing test output from feeding back into model or rules.

02

Load fallback on demand

The legacy model is loaded only after retries fail, avoiding permanent dual-model GPU use.

03

Deterministic post-processing

Safe rules cover known navigation terms; experimental place-name rules remain isolated.

04

Validate again at build time

Final output is checked for UTF-8, JSONL, IDs, fields, and obvious generation anomalies.
